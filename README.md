# Pixelwright

A pixel-art 3D world builder and game maker that runs in the browser.

## Put it on GitHub Pages
1. Upload everything in this folder to a GitHub repository, keeping the `icons` folder.
2. In the repository, open Settings → Pages, choose "Deploy from a branch", pick your branch and the root folder, and save.
3. Open the address GitHub shows. On iPhone, tap Share → Add to Home Screen to install it with its icon. It keeps working offline after the first visit.

Your worlds save in the browser on each device. Use Create → Game → World → Back up world to keep a copy.
