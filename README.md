# Pixelwright

A pixel-art 3D world builder and game maker that runs in the browser.

## Put it on GitHub Pages
1. Upload everything in this folder to a GitHub repository, keeping the `icons` folder.
2. In the repository, open Settings → Pages, choose "Deploy from a branch", pick your branch and the root folder, and save.
3. Open the address GitHub shows. On iPhone, tap Share → Add to Home Screen to install it with its icon. It keeps working offline after the first visit.

Your worlds save in the browser on each device. Use Create → Game → World → Back up world to keep a copy.

## Play together
Hosting uses free player-to-player connections (WebRTC through the public PeerJS server), so there is no server to run. The host's app must stay open. Guests open `?join=CODE` on your Pages address, or tap Map → Join a world and type the code.

## Safety (App Store guideline 1.2)
Chat is filtered by default (players can switch it off), players can mute or report anyone, hosts can remove players, and everyone agrees to the community rules before hosting or joining. Reports open an email to jacoblc22@gmail.com with the player's name, the world code and their recent messages. Answer reports within 24 hours.
